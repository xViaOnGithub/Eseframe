  • loaded compound

          • ingredients list
            1. compound
              • items string or list
                1. "[namespace:item_id]" string
                2. ...
              • min_count (optional) integer
              • slot (optional) integer list
              • components (optional) compound
              • predicates (optional) compound
            2. ...
          • results compound
            • loot (optional) string or compound
            • function (optional) string or compound
              • path string
              • data (optional) compound
            • advancement (optional) string
        • ...
      • recipe_ids list
        1. "[recipe_id]" string
        2. ...
    • ...
  • disabled compound
    1. [recipe_group] list
      • "[recipe_id]" string
      • ...
    2. ...
