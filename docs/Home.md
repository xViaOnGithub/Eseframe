# Eseframe

*Looking for the download link? #todo Click here *

Eseframe is a library for adding custom items and recipes to Minecraft: Java Edition worlds without requiring mod loader. Beginning as a fan-made [datapack](https://minecraft.wiki/w/Data_pack) port of [Slimefun 4](https://github.com/Slimefun/Slimefun4), it has since shifted it's focus to making custom items and recipes easy for datapack creators.

Eseframe is made up of two namespaces: `eseframe`, which contains the internal logic to enable custom items and recipes, and `eseframe_api`, a front-end of simple but powerful features that other datapacks can hook into. Features in the API include the ability to add custom items, a recipe format that can detect [item components](https://minecraft.wiki/w/Data_component_format), and more! #datapack-todo
